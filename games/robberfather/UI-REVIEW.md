# 한 끼의 무게 — UI v7 검수 기록

대상: 한국어, 게임 뷰포트 1280×720. 사용자가 고른 U6 방향은 **가벼운 톤 + 비네트 제거**입니다.

## 변경 및 자체 비교

| 번호 | 자체 판정 | 바꾼 것 | 남은 것 |
|---|---|---|---|
| U1 | 해결 | 게임 밖 헤더·장소·키 안내·이야기·푸터 삭제. 타이틀은 제목·한 줄 소개·시작/이어서 하기. 게임은 창 전체 사용. | 없음 |
| U2 | 해결 | 돈·식사·남은 기회를 아래 한 묶음의 아이콘으로 통일. 중복 HUD 삭제. 금색 기회 2개 = 두 번 남음. | 처음 보는 외부 플레이어의 실제 3초 응답 실험은 미실행. |
| U3 | 해결 | 첫 대화 해설 삭제, 다음 버튼, 아이를 가리키는 꼬리. 튜토리얼 부연 삭제. 주머니 안내 한 줄·고정 배치. 안내는 가격표 포함 원문 기준 296자. UI 마감 용어는 ‘밤까지’. | 이야기 대사 원문은 요청한 이야기 보존 원칙에 따라 유지. |
| U4 | 해결 | Esc 첫 화면은 계속·음량·조작키·안내 네 버튼. 설정과 조작키 표는 하위 화면. | 없음 |
| U5 | 해결 | 이동/달리기/출입/사용/맞추기/숨기/두고 가기/버리기/귀가로 통일. 주머니는 E로만 닫고 A/D를 무시. Space 설명을 같은 안내에 포함. 변경한 키도 안내에 반영. | 없음 |
| U6 | 해결 | 명조 UI를 읽기 쉬운 고딕과 짧고 가벼운 표현으로 변경. 검은 가장자리 비네트 제거. | 발각을 알려 주는 빨간 시야 경고는 기능성 표시로 유지. |

‘해결’은 구현과 아래 자체 검수를 뜻합니다. 기존 gamedesign-study 평가 자료/평가 에이전트 세션은 이 작업 환경에서 찾지 못했습니다. **같은 평가 에이전트에 의한 재평가는 수행하지 않았습니다.** 아래 캡처를 비교 자료로 제공하며, 외부 재평가 결과를 대신 작성하지 않았습니다.

## 검증

- 브라우저 실제 1280×720 iframe에서 게임 stage 1280×720, 페이지 가로·세로 초과 0px, 스크롤 위치 (0, 0).
- 게임 밖 UI 0개, 자원 묶음 3개, 돈/식사 행 각각 1개.
- 일시정지·조작키·안내 하위 화면 내부 스크롤 0px. 안내 가격표 1개.
- 소매치기 중 A/D 후 창 유지, E 후 닫힘, 곧바로 Space 후 닫힌 상태 유지. 주머니 제목과 한 줄 안내는 최초 표시부터 보임.
- `node --test tools/robberfather.test.mjs`: 21개 통과. 강제 E 튜토리얼, E/Space 동시 입력, 키 변경, 음량, 돈/음식 구분 등 포함.
- 단일 HTML 빌드 완료, 묶인 18개 모듈 문법 검사 통과.
- 이번 UI 작업 전 커밋 `663dfc7` 대비 engine/backgrounds의 차이는 모듈 캐시 주소뿐. story.js, characters.js, 그림 자산은 변경 없음. 소매치기 입력의 취소 키 정리 외 규칙/밸런스 변경 없음.
- 기존 세이브 저장소 키 및 버전 유지. 검수 장면은 4178 포트의 별도 저장소에서 실행해 4174의 플레이 저장을 덮어쓰지 않음.
- 확인한 범위에서 새 UI 문제 없음. 모바일과 외부 사용자 평가는 이번 대상에 포함하지 않음.
