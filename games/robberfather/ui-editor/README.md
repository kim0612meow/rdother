# 게임 내 UI 편집기

## 사용법

ESC → UI 편집. 게임 시간, 조작, 소리를 멈춘 상태에서 편집합니다.

- 화면 요소를 드래그해 이동하고 오른쪽 아래 손잡이를 드래그해 크기를 바꿉니다.
- 목록에서 요소를 고르면 숨겨진 대화·미니게임·컷씬 UI도 미리 볼 수 있습니다. 미리보기는 UI만 표시하며 이야기나 게임 상태를 변경하지 않습니다.
- 위치·너비·높이는 게임 창에 대한 백분율입니다. 너비·높이·글자 크기 0은 원래 값을 유지합니다.
- 색, 불투명도, 글꼴을 바꿀 수 있습니다. 되돌리기/다시 적용, 요소/전체 초기화를 지원합니다.
- 저장은 `one-more-meal-ui-layout-v1` 키로 현재 브라우저에만 기록됩니다. 게임 세이브와 독립적입니다. 저장하지 않고 닫은 변경은 취소됩니다.
- JSON 내보내기/불러오기로 다른 브라우저에 옮길 수 있습니다. 불러온 뒤 저장하세요.
- 전체 플레이어의 기본 배치로 쓰려면 내보낸 JSON을 이 폴더의 `layout.json`으로 교체해 배포합니다. 기존 브라우저별 저장이 있으면 그 값이 우선됩니다.

## 분리 구조

- `index.js`: 편집기 UI·드래그·입력 차단. `ENABLE_EDITOR=false`로 바꾸면 편집 메뉴를 없애면서 저장된 레이아웃은 계속 적용합니다.
- `model.js`: 편집 대상 목록, JSON 검증, 안전한 CSS 생성.
- `runtime.js`: 저장된 레이아웃/공유 기본값 적용과 창 크기 대응.
- `styles.js`: 편집기 전용 스타일. 게임의 game.css를 변경하지 않습니다.
- `layout.json`: 공유할 기본 배치. 기본값은 원래 게임 배치입니다.

완전히 제거하려면 app.js에서 `installUIEditor` import와 초기화 호출, `uiEditor` 선언, 프레임의 `uiEditor?.active` 조건을 제거하고 이 폴더를 삭제합니다. 다른 게임 로직·HTML·기본 스타일은 편집기에 의존하지 않습니다. 초기화 객체의 destroy()도 이벤트·스타일·DOM을 정리합니다.

게임 캔버스 안에 그려진 배경·캐릭터·미니게임 내부 그림은 대상이 아닙니다. 편집 대상은 HTML HUD, 버튼, 대화/미니게임/컷씬 패널입니다. 원문 대사는 i18n.js/story.js에서 관리합니다.
